## 3. Protected invariants

No NVM clear/factory reset shortcut; preserve IEEE/PAN/EPAN/channel/key; fresh recovery point before destructive work; one serial owner; no re-pair to hide faults; hash every image; rollback recoverable; no flash from CI success alone; KCTRL routing/retry/timing preserved; capacities not a fix; NVOCMP policy unaltered; failure spins preserved; sync lifecycle observed, never bypassed; diagnostic traffic never prioritized; no keys/payloads/credentials in logs; no live HA/modem actions by this executor.
