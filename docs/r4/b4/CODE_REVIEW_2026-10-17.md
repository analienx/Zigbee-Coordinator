## Negative/hostile test matrix (author-performed, not independent)

- F0 success → artificial timeout → delayed valid F0 frame → second F0 is **rejected** before the UNPI writer; a normal SYS_PING still responds.
- Synchronous F0 writer failure occurs **before the waiter timer begins** → diagnostic waiter removed, no serial reset/retry, F0 quarantined.
- Invalid unqualified counter word, reserved bits, nonprogressing or zero sample sequence → refused; no fake radio boot epoch.
- Simulated 200 competing diagnostic offers → one existing-owner request; 40 independent stock SYS_PING complete through pinned `Znp.request` mutex/waiters. This remains in-memory synthetic load, not RF fairness.
- Persisted recorder symlink race, schema/secret injection, malformed/partial MT frame, invalid counter wrap, manufactured NV/USB causes → conservative rejection or UNKNOWN.
